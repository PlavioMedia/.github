# Plavio Media

Home of **Plavio** — a free, open-source streaming app for Android and Android TV.

Movies, series and live TV in one place. A fast built-in player, addon support, downloads, and your library with you on every device. No account needed, no tracking.

**Download:** [plavio.site](https://plavio.site) — the latest version is always in [Releases](https://github.com/PlavioMedia/Plavio/releases).
